# Satyajit Study Sphere

First prototype of a personal educational resource website.

## Included
- Responsive homepage
- Competitive exam categories
- Study material cards
- Current affairs section
- Answer writing section
- Motivation and healthy-study section
- PDF library placeholder
- Search over sample resources
- Mobile navigation

## Free launch
Use GitHub Pages:
1. Create a public repository named `satyajit-study-sphere`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Save and open the generated `github.io` address.

## Before launch
Replace sample content with your original/permission-cleared material. For third-party PDFs, articles, images or quotations, check copyright/licensing and link to the original source where appropriate. Health content should be educational, evidence-based and not presented as personal medical advice.
